# Reliability audit — 2026-11-18

## シェル出力の完了待ちと未完了の値の返却

The output thread had unbounded capture, and a two-second join could return incomplete data. Apply one deadline to output and process completion, reject oversized results, and clean up the child on failure or cancellation. Monitoring and SIM selection policy are unchanged. Add source-build CI; it requires no device or credentials.

No feature switches, boot preferences, signing identity, target scopes or Android 16/17 compatibility gates are changed. This is a source fix and regression check, not proof of physical-device behavior. No release APK is distributed by this audit.
