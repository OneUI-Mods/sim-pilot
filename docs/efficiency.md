# CPU・メモリ効率の見直し（1.10.1）

## 変更

通信量取得用のワーカーを待機時に解放します。SIM切り替え・無線監視・速度測定の間隔、通信量の15分キャッシュは変更しません。

直列ワーカーの順序・キュー・例外・終了操作は維持します。30秒の無処理後にスレッドのみを解放し、次の要求で再作成します。処理中の仕事や待ち行列を破棄せず、定期確認や描画の間隔を伸ばす変更はしません。各アプリに実装を同梱し、他のアプリや共有サービスには依存しません。

## 検証の範囲

既存のユニットテスト、releaseビルド、lintで回帰を確認します。直列ワーカーは、処理中に積んだ20件が順序どおり実行され、待機後にスレッドが解放され、次の要求を再実行できることをテストします（採用アプリ）。Adaptive Barでは旧方式との配色結果・サンプル座標の一致、管理アプリでは通知の集約と描画中の更新保持も確認します。

この変更の検証はホスト上で実施しています。実機の画面操作・音声再生・対象プロセスの再起動は行っていません。端末全体のCPU使用率・PSS・FPS・電池消費の改善量を実測したものではありません。既に動いているフックへ反映するには、通常のアプリ更新に加え、その対象プロセスの次回起動が必要です。

## ホストでの確認結果

- ユニットテスト: 58件成功。
- releaseビルド・release lint: 成功。
