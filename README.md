# SIM Pilot

デュアルSIM端末で、データ・通話・メッセージの既定SIMを別々に管理するアプリです。電波と通信品質を比較してデータSIMを自動切り替えできます。

## 主な機能

- 手動切り替えと、通信品質が低下した時の自動切り替え。
- Wi-Fi接続時の復帰先をデータ・通話・メッセージごとに指定。
- SIM別の電波・セル・通信品質の表示。
- 月次・期間指定・複数トッピング・手動残量に対応したデータプラン管理。
- 通話中の切り替え抑制、連続判定とクールダウン。
- 消灯中の監視停止、起動・更新後の自動復帰。
- Material 3の「ホーム」「無線」「設定」と、端末内の診断ログ表示・書き出し。

## 対応環境・初期設定

Android 12以降の対応するDSDV端末とShizuku / Shizuku Plusが必要です。主な実機確認環境はGalaxy S26 Ultra（SM-S948Q）、Android 16 / One UI 8.5です。他のOS・端末では、端末の切り替え方法を検出できた機能だけを有効にします。SDK 37向けのビルドであることと、Android 17で全機能を確認済みであることは同じではありません。

1. [Releases](https://github.com/OneUI-Mods/sim-pilot/releases)から配布APKをインストールします。
2. Shizukuを起動してSIM Pilotへのアクセスを許可します。
3. 電話・位置情報の権限を許可し、必要に応じてバッテリー最適化の対象外にします。
4. 「設定」で品質判定とWi-Fi接続時の動作、データプランを確認します。
5. 「データSIMを自動切替」をONにします。

## 通信量・制限

品質の測定には通信を使用します。Wi-Fi接続中は自動フェイルオーバーを止め、消灯中は監視・通信測定を停止します。切り替えや比較で通信が一時途切れる場合があります。通話中の切り替えは抑制しますが、すべての通信アプリの継続を保証する機能ではありません。

残容量の集計にはOS側の遅延があります。請求や正確な残容量は通信事業者の案内を確認し、必要なら手動残量を使ってください。自動復帰がONでも、Shizukuが起動するまでは切り替えを待ちます。

## プライバシー・停止

診断ログは端末内へ保存します。電話番号・ICCID・IMEIは記録しません。回線名、電波値、セル識別情報、通信量、切り替え履歴を含むため、ログを共有する前に内容を確認してください。疎通確認にはAndroidの接続確認先、速度測定にはCloudflare Speed Testを使用します。

自動切り替えを止める場合はスイッチをOFFにします。必要ならデータ・通話・メッセージの既定SIMを手動で戻します。
